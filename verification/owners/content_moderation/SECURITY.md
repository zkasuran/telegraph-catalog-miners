| Attack | Defence | Test or remote control |
|---|---|---|
| Local neural execution | Closed owned-workflow guard before neural entry points | Local guard tests |
| Audit-driven tuning | Trainer read denial, frozen selection, exclusive audit marker | Fake read-denial and freeze controls, remote marker |
| Source or model substitution | Immutable source hashes, package SHA-256, class snapshot, full parser | Local hash controls and real remote parser |
| Tracing perturbs training | CPU RNG fork plus Python/NumPy restoration | Fake local controls and real remote positive/negative fixture |
| Weak class hidden by aggregate | Every format and label required | Synthetic quality failure controls |
| Shortcut scoring | Train-only fitted coefficients, frozen byte hash, strongest-rule comparison | Frozen-coefficient controls and remote results |
| Wrong literal wire identity | Bare-hash output equality, actual reference bridge | Fake HTTP smoke and real remote controls |
| Nonfinite or missing scores | Strict finite FP32 and count checks | NaN, infinity, missing and duplicate controls |
| Untrusted remote time/size | Phase/process-group ceilings, body limits and source hash ceilings | Source gate plus remote phase logs |
| Credential or endpoint takeover | Only existing proxy, ephemeral restricted runner key, public lease only | Lease contract validation by automatic adapter |
| Fitted checkpoint presented as untrained | Separate immutable warm-start and genuine untrained asset hashes | Explicit source gate and distinction failure controls |
| Recovery substitutes model or sample | Original ZIP/member/package hashes, full repeated-stream comparison, identical 256 audit groups | Recovery archive and mutation controls |

F3 uses a fresh low-LR optimizer from a validation-selected H9 snapshot. It is
not exact optimizer/RNG continuation. The H9 failure is not relabelled passing.
Source-only checkpoint term checks verify original grants in both containers
before publication. Successful registration evidence is separate from large
epoch diagnostics; the adapter's archive ceiling is not weakened.

The original F3 audit was opened only after epoch 1 was frozen. Qualification
timed out after the trained streams completed. Runtime-only recovery may complete
the missing untrained measurement, but cannot fit, select another candidate or
reduce the audit. Original run/commit identities remain attached to the complete
result alongside the actual recovery job. ZIP expansion and members are bounded.

B3 is a new source-anchored training hypothesis after a genuine audit loss. Its
clean audit excludes every previously exposed audit group and all original split
groups before model loading. Full official test-file scanning removes conflicting
source groups. Tests cover reverse scan order, deep candidates, exclusions and
insufficient sources. Training style rotation admits only train groups and keeps
both labels equally represented in each style. The upstream anti-repeated-negative
gate remains unchanged. Exact bare labels are not trained and must still pass
the full validation and independent reference-engine gates.

Run 44745877586 stopped before model loading at the train-only shortcut gate.
The response correction uses ordered accepted/excluded verdict roles with equal
word bags and lengths, not random tags, stock answers or lower thresholds. Tests
check source truth, opposed verdict roles, exact word-count equality and unchanged
shortcut results. The still-unscored source audit is pinned by its actual hash
and complete group identities before any new model work.

M2 expands the legitimate source population after a real model quality loss.
It scans every row of both pinned training shards, validation and test before
selection, recording cross-split and conflicting normalized groups even for
non-extreme annotations. Source-only complete-token admission precedes freezing
train/validation/audit bytes. All 512 previously exposed audit groups are excluded
globally. Tests use late conflicting rows, reversed input order, missing shards,
insufficient clean groups and changed prepared split bytes. Every model quality
gate remains unchanged. Temporal/publication grouping is not available in these
pinned Parquet fields and is not claimed.

The candidate release binds exact emitted bytes to its actual successful GitHub
run, full Go parser, reference logs and combined registration report. Local
checks hash the package/source proof and inspect inert grants without loading a
model. Failure tests mutate actual tensor bytes, source proof, literal hash form,
runtime identity and per-label quality. The automatic adapter independently
recomputes Keccak and checks live vectors before signing. The served executor
remains at the audit report's original source commit; publishing proof bytes does
not replace the runtime or authorize another audit draw.

No hidden-pool or development-exposed audit input is permitted. No neural model
is loaded locally. Source publication alone is not qualification. The runtime
bridge returns the identical engine's score bits, not a Torch substitute.

Known limits: one seed, narrow English extreme-toxicity proxy, unknown foundation
pretraining overlap and same-source held-out audit. Source-only tests do not
verify neural quality. Go compilation and actual reference-engine execution are
mandatory remote gates. Five-hour free serving leases require byte-preserving
renewal, not a new registration lottery. No paid infrastructure is created.
