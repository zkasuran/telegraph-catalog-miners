# Keep IP evidence tied to its source

This reference grades whether a JSON answer preserves conditional address evidence from a frozen set of ET Open detection rules. It catches omitted source rules, wrong IPs and overstated current maliciousness. It does not determine whether an IP is currently malicious or benign.

## Try the source contract

From this directory, run `bash verify.sh`. The gate needs Python 3, Bash and no additional packages. It checks exact source-card identities, literal JSON envelopes, CIDR boundaries, mapped IPv6 aliases and source snapshot age. It requires deliberately broken implementations to fail assertions. No neural imports, model loading, inference or network access occur.

Run the CLI on an included mechanical fixture:

```sh
python3 -W error reference.py --sources . --request smoke-good.json
python3 -W error reference.py --sources . --request smoke-overclaim.json
```

The honest answer returns score 1.0 and exit 0. The constructed maliciousness overclaim returns 0.0 and exit 1. Malformed or ambiguous outer JSON returns an `invalid_request` JSON error and exit 2, without a traceback. These fixtures are not captured miner responses.

The input envelope has exactly two string fields, `prompt` and `answer`. The prompt binds an IP literal, explicit UTC as-of, frozen capture time and source-card hash. The answer has exactly `ip`, `rule_ids`, `evidence_state`, `current_abuse` and `basis`. This is a narrow reference contract, not a claimed published miner schema.

## What the evidence means

Eight licensed ET malware-rule cards cover six normalized /24 source/entity groups. The cards were selected after inspecting 44 complete ET-named rule-source files. The full inventory contained 59 entries. Generated third-party feed rules stayed outside the selected source. The reference pins the complete source selection rather than trusting an editable list to include every relevant rule.

A source address predicate does not execute the rule's payload conditions. A rule edit date is not a last-seen timestamp. Current abuse therefore stays unknown. The explicit 24-hour snapshot TTL is reference policy, not an upstream promise about observation freshness or address reuse. Non-membership is not a benign label.

The literal judgment render expression is retained under its original MIT grant and tested character for character. Tokenization, neural scores and the FP32 reference engine are not executed. This package emits `SOURCE_REFERENCE_VERIFIED`, never a registration-ready report.

## Qualification boundary

This package is an auxiliary source-evidence reference, not a live-qualified neural judgment adapter. There is no training, validation or independent audit dataset here. Six source/entity groups do not meet the unchanged qualification minimum of 32. Current-positive IP observations with an approved commercial training grant remain an open gate.

The source-only public CPU workflow runs the same gate and may emit a bounded report binding its actual GitHub run, commit, file hashes and runtime identities. It does not train, serve or register a model.
