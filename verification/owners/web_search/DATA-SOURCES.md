## Authorship and independence

Source metadata assertions are original. Compact fact sentences, queries and version swaps are programmatically constructed by AI-assisted code. They are not human-reviewed annotations. New competitive code and additions use SAND subject to unchanged upstream grants. Neither selected documentation grant requires share-alike. No evaluation-pool row or exposed development audit was used as new data.

Entire Python page histories stay in train or validation. Node pages and their release snapshot stay audit-only. Baseline coefficients and frequencies are immutable training fits. Validation may choose the frozen model. The independent audit is measured once after export. Page identity, normalized API names and normalized answer text are checked for overlap. Audit pairs on one page are not separate independent groups.
