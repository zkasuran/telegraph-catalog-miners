question. The default AdapterInput function preserves the raw candidate body.

actual deployed scoring prompt. Shaping a miner's own body does not authenticate
it. A genuine independent canonical caller proof is required before neural mode.

data. Pinned source code and aggregate schema metadata are not model labels.
