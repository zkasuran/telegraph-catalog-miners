# Source-bound smart audit threat model

| Attack | Defence | Test or limit |
|---|---|---|
| Incorrect generated vulnerability label | Every source compiles and its disputed call runs in an offline EVM | `failure_controls.py` flips a label and requires rejection |
| Fake compiler pass | Zero compiler diagnostics, exact returned values and stored effects | `execute.mjs` positive plus legitimate controls |
| Invalid or substituted source | SHA-256 binding and compiler rejection | Unit tamper check plus invalid-source runtime control |
| Training leakage | Whole designs and vulnerable/fixed siblings remain grouped | Normalized clone and group-leak negative tests |
| Repeated formats counted as independent sources or audit leaks | Development views retain original source groups and accept train/validation only | View preservation, three-format coverage and audit refusal controls |
| Annotation shortcut | No vulnerability annotation in source, both reports share finding words | Length, answer-only and overlap checks |
| Candidate trained on audit | Training extension accepts only original training pathways; validation/audit bytes remain pinned; separate audit job receives already frozen package hashes | Original-row, held-out hash and sibling-group preservation tests plus automatic adapter recheck |
| Weak candidate consumes the audit during tuning | Saved-best exported bytes must pass all unchanged validation format/subgroup/baseline gates first; validation cannot emit registration-ready | Pure split-boundary refusal/control test and actual reference-engine validation before audit job |
| Average selection hides a failed format or label | Validation-only selection maximizes the minimum margin to each existing format/label/mechanism gate; actual average remains reported | `test_selection.py` favors a balanced lower-average candidate over an uneven one; audit/train and missing cells are refused |
| Trainer-source drift or unsafe local adaptation execution | Exact pinned primary trainer SHA-256 and four unique source anchors; compilation only in the source gate; remote authority before adapted module execution | Actual primary-source compilation plus wrong-hash and local-execution refusal controls; original kit source untouched |
| Truncated guard or precondition | Reject any full render above 384 authoritative tokens | Remote tokenizer check, not run locally |
| Endpoint returns another model | Exact foundation, tokenizer, adapter and token-root echo | Pinned literal client test plus real remote audit |
| Floating baseline refit drift or stale training identity | New training version has its own immutable integer baseline; original coefficients remain byte-identical | Train-identity binding and old-file SHA-256 regression |
| Local neural operation | Guard before any neural import or download | Local authority refusal test |
| Parser failure hidden by a wrapper | Persist actual stdout/stderr before checking exit status; a dedicated remote mode checks frozen packages without retraining | Diagnostic entry refuses local execution; run 44598067975 passed full parsing of the frozen originals |
| Stale or guessed model classification | Exact live family/child URLs, source hashes, freshness and matching model classes before private loaded-class parser call | Wrong class, wrong identity and stale-source refusal controls; no compiled/shared catalog edit |
| Private or unrelated job repository | Exact owned identity and boolean public flag from the hosted dispatch payload; protected default environment context | Positive public control plus private, ambiguous and wrong-repository refusal controls |
| Missing or malformed collator input | Default only omitted margin to 0.0 at the training boundary; reject nonfinite/nonnumeric values without mutating source | `test_contracts.py` literal-text preservation and invalid-margin controls; primary CLI smoke |
| Resource exhaustion | 256 rows, 2048 source bytes, 8192 bytecode bytes, 1 million interpreter gas, bounded subprocess/HTTP timeouts and eight serving connections | Wrong source and control tests; serving refuses malformed tokens before inference |
| Variant-rich training implementations dominate fitting | Frozen train-only integer weights equalize expected implementation mass while retaining corpus bytes and the dataset gate | Pure weight/identity/refusal controls; actual 12000-draw/repeat/refusal controls passed in run 44672243024, not evidence of model improvement |
| Minibatches reinforce source-independent answer or label bias | Both vulnerable/fixed source siblings and reversed literal preferences in each training minibatch | Pure complete-pair and analytical opposed-loss controls; actual DataLoader/batch identity checked on runner, no improved accuracy claimed locally |
| Wrong sibling, changed call facts or normalized answer matching | Require exact two-row sibling/format identity, same facts, distinct source hashes and literal reversed strings | Missing sibling, same label, changed answer, changed facts and audit-input refusal tests |
| Incompatible custom DataLoader batching | Use batch_sampler without conflicting batch_size/sampler/shuffle arguments; retain two rows and accumulation four | Primary source syntax and actual remote DataLoader/repeat/length controls; expanded training has 216 batches/54 updates, not new independent sources |
| Training identifier augmentation copies held-out data or inflates independence | Original training-side generators only, exact old-row and held-out byte checks, unchanged group IDs | `test_identifier_variants.py` retained full training/held-out hashes and no new-group count; full compilation/disputed-call/legitimate checks |
| Exposed audit becomes training or a repeated qualification draw | Permanently retired audit fingerprint, generator refusal for retired design IDs, active clean audit must have a different hash | `test_audit_retirement.py`, source-binding runtime guard and immutable exposure ledger; no old audit row is used in new fitting/test data |
| Rational sampling secretly refits or bypasses old integer limits | New immutable numerator/denominator schema binds exact training counts; legacy bounded integer schema remains unchanged | Exact rational group-mass test, changed denominator refusal and held-out input refusal; old invalid-integer tests retained |

## Known limits

This is not a production contract audit. It tests only self-contained setter authorization and bounded arithmetic effects. It does not establish reentrancy safety, complete exploitability, mainnet state or universal factual truth. High lexical overlap remains despite whole-design splits. Source and claims share AI-assisted authorship. There is no independent human adjudication.

No credentials, wallets, transaction objects, signing or RPC calls are used in local verification. The interpreter evaluates bytecode directly in disposable memory. Neural and serving jobs are bounded standard public CPU tests. The serving runner creates only its own ephemeral restricted forwarding key. Only its public lease is exported. Testnet signing and endpoint activation remain inside the installed automatic adapter. No canonical qualification is established by source checks alone.
