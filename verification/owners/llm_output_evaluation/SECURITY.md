# Threat model

| Failure or attacker | Defence | Verification |
|---|---|---|
| Oversized or substituted source | Complete four-payload SHA-256 inventory and download/expansion/row ceilings | source_gate.py, frozen pins and original inventory |
| Source overlap | NFKC/casefold prompt/output connected components and disjoint whole-source groups | data.py and transitive overlap failure test |
| Label retained after cropping | Never crop task/output; reject complete rendering beyond token cap | byte-ceiling test and remote token visibility check |
| Surface shortcut | Immutable integer train-fitted coefficients, length/overlap/rating controls and unchanged primary gate | data.py and primary trainer source |
| Audit-selected candidate | Separate audit job after package/data/baseline freeze, once-only marker and rerun refusal | runtime_audit.py |
| Missing rating label silently omitted from audit slices | Require every supported label, reject unknown labels and nonfinite scores before computing quality metrics | test_audit_metrics.py executes actual pure source with synthetic controls; ties remain losses |
| Synthetic wire success mistaken for node proof | Literal primary render expression plus real reference-engine audit | wire.py; synthetic HTTP tests are labelled and do not qualify a model |
| Identity substitution | Literal bare-hash request/response equality, package/engine/tokenizer hashes and finite bits | test_wire.py and actual negative identity probes |
| Run metadata callback used for a wire row | Keep proxy wire_identity separate from the run metadata callback; preserve both literal contracts | test_runtime_identity.py executes the actual nested audit source with synthetic service doubles and reproduces the unfixed TypeError |
| Native/reference tokenizer drift | Compare complete token arrays, canonical CLS/SEP and bounded integer IDs without padding removal or cropping | test_token_contract.py provides source-only controls; actual tokenizer parity runs remotely before training and audit scoring |
| Laptop neural execution | Guard before model imports; public github-hosted CPU workflow only | refusal unit test and workflow schema validation |
| Partial dependency audit mistaken for complete clean supply chain | Match the exact complete canonical name/version set, refuse aliases/duplicates, missing vulnerability records and malformed JSON; retain failures as unknown counts | test_audit_dependencies.py runs the actual wrapper under synthetic auditor doubles; the real advisory audit remains remote |
| Lost failed checkpoint terms | Full source/model/code grants and inert metadata records | licensing.py, payload-preservation test and remote export/readback |
| Endpoint takeover | Immutable package/report binding, recorded vectors and common.lease_for public restricted lease | serving.py; signer credentials never enter the runner |
| Partial ready report enters serving preparation | Validate the full pinned identities, independent source proof, all formats/labels, unchanged quality margins and bounded finite vectors before fetching the package | test_serving_contract.py executes the actual source prefix with synthetic no-model path/fetch/env doubles; the activation adapter independently rechecks the real report |

## Limits

No source-held-out score proves hidden node quality. Human helpfulness is not universal factual truth. Processed miner application fields may differ from this public qualification prompt/body and no equivalence is claimed. JSON assessment text is not a canonical processed rating field.

No complete PII-removal or underlying ShareGPT-rights guarantee is made by the dataset grant. Resolve identified privacy or third-party-rights objections before publication. Audit rows that have been scored or exposed are never reused to tune a later candidate. Package/runtime identity recovery preserves bytes rather than retraining blindly.

The runner uploads only public lease JSON, never its ephemeral forwarding private key. The installed automatic adapter alone owns proxy activation and Telegraph signing. No paid or self-hosted compute is allowed. All serving is bounded by the existing five-hour lease and requires renewal through the same qualified candidate, not an unresolved replacement.
